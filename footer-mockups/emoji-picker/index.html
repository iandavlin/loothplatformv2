Two things I found that change the brief

1. Messages are not in the BuddyBoss table — they're in Postgres. The brief said the emoji-safety check was done against wp_bp_messages_messages (MySQL, utf8mb4). The DM composer doesn't write there. It posts to /profile-api/v0/me/messages/ → profile-app/src/Messaging.php → the Postgres messages table. I re-checked the store that's actually used: profile_app is UTF8 database-wide and body is text, so 4-byte emoji are safe — Postgres has no 3-byte/4-byte split for MySQL's trap to apply to. Same conclusion, different database, and now it's checked against the real one.
Also verified: every truncation on the path is mb_substr/mb_strlen, never byte substr — so a snippet can't slice an emoji in half. Still gets proven end-to-end rather than argued.
2. You ruled against a picker on 2026-07-13 — for reactions, not for this. Messaging.php records it: "the FIXED reaction set (Ian 2026-07-13: no full picker, no keyboard — this is a phone-first surface)". That ruling is about reacting to a message, and I'm not touching it — reactions stay the fixed six, server-validated. This is the composer, a different surface with the opposite rationale: it's desktop-led, and typing prose is not the same act as tapping a reaction. Worth you seeing the tension explicitly rather than finding it in the diff later.
What it will and won't share with reactions.
  • Shared: the visual language — same native-emoji approach, same button shape, same one-picker-open-at-a-time behaviour.
  • Shared: the six reaction glyphs open the picker as "Frequently used".
  • Not shared: the fixed six can't be the composer's whole vocabulary — a picker that only offers six emoji is not a picker. Composer emoji are ordinary text inside the message body; reactions stay structured rows in message_reactions. One emoji system, two jobs — not a second react system.
It's four composers, not one. Desktop modal has #lg-msg-reply-input and #lg-msg-side-input; the phone sheet has #mg-in and #mg2-in. All four get the picker, or members will find the one that's missing it. I'll gate all four.
