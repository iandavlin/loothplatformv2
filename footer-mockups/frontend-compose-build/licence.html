How a member changes it

The first option is the important one. “Follow the post’s licence” is the default: the page reads the licence from the post’s own details every time it renders. So when a member changes their licence in the form, the page changes with it.

That matters because everything else on a loothprint page is baked in at the moment it’s built. It’s the same fault as the print-files ZIP I reported: swap the file, the page keeps serving the old one, and because it still downloads, nobody notices it’s wrong. The licence had that fault too. It no longer does.

One question for you

The fourth choice contradicts itself, and it’s in the form, not the block.

It reads: BY ND NC (Credit given to creator, No Derivatives, Adaptations shared with same terms).

No Derivatives means nobody may publish a modified version. Adaptations shared with same terms is a rule about modified versions. They can’t both be true — if there are no adaptations, there is nothing for the second rule to govern.

The code it names, BY-NC-ND, is a real licence, so that is what the block draws: credit, non-commercial, no derivatives. I dropped the impossible share-alike part. I have not touched the stored wording — 3 posts use it, and rewording a licence members already agreed to is your call, not mine.

Want me to fix the wording in the form? One line, and those 3 posts keep the same licence either way.
