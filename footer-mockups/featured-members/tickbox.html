What it buys. Room for the full sentence and for state the member might want (“in the pool since…”, “you were featured in July”). What it costs. A fourth permission control that lives somewhere other than the other three, plus its own block, its own visibility rules and its own gate.

The state that is easy to forget

A member whose profile is Private is owner-only — no directory card, no map pin, no search hit. Featuring them on a public front page would undo that in one click, so the tickbox has to be unavailable, and say why.

Profile visibility = Private → consent unavailable
Profile visibility Private Only you (and site admins) can see your profile. You are removed from the directory, the map, and search until you switch back.
Featured member Unavailable while your profile is Private — the front page is public. Set your profile to Public to opt in.
