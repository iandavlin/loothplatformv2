One at a time (your ruling): featuring James would take Beau down in the same click, and the history records both.
Why there is no dark version of the dash. The dash is a WordPress admin page, and the member theme picker does not reach WP admin — it styles the member-facing site only. So a dark rendering here would be a fiction. If you want a dark admin, WordPress has its own admin colour schemes (Users → Profile → Admin Colour Scheme) which apply site-wide to every admin page, not just this one. Say the word and I will draw it in whichever scheme you use.
What the dark pass changed. Three fixes, all in the new pieces and all made before anything is built: the consent card's body text and its “in the pool” background, and the meter's item text, track and ticks were all fixed light values that would have gone unreadable on a dark card. The existing surfaces (privacy bar, front-page band) already had their dark handling and needed nothing.
