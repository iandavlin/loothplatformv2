**2. Deploy the UNIT — a pull does NOT do this.** `/etc/systemd/system/

      sudo cp ~/keeper-repo/platform/systemd/approved-watcher.service \

      sudo systemctl daemon-reload || echo WRONG BOX

**3. SEED THE ONE-SPIN LOG — do this BEFORE step 4, not after.** The
branch-exists backstop already refuses every parked lane, but seeding is belt
and braces and costs one command. It records the issues that have already had
their seat:

    cd ~/keeper-repo && for n in 106 107 129 132 138 148 150 155 165 169 170 172; do
      grep -qx "$n" ~/.autospin-log 2>/dev/null || echo "$n" >> ~/.autospin-log
    done; sort -n ~/.autospin-log

**4. WATCH ONE DRY-RUN DECISION.** Dry-run is the default; the merge arms
nothing. Within 5 minutes the board should carry either silence (nothing staged)
or a `DRY-RUN: WOULD SPIN <lane> for #<n>` line. **Read it and check the lane
name and the numbers are the ones you would have typed yourself.** That is the
one observed correct decision the charter asks for.

To manufacture that decision deliberately: stage a charter at
`~/lane-prompts/<n>-<slug>.md` for an open+approved issue, cut its worktree, and
wait a tick.

**5. FLIP IT.** One file, no code edit, no restart:

    echo live > ~/.autospin-mode

**6. Reverse it** at any time — either kill the mode file or set the hold:

    rm ~/.autospin-mode          # back to dry-run
    touch /tmp/keeper-quiet      # stop all spins, this session
    touch ~/.keeper-quiet        # stop all spins, across reboots

## The state files, and who owns them

| File | Owner | Meaning |
|---|---|---|
| `~/.approved-acks` | phase A | issues already rung |
| `~/.autospin-log` | phase B | issues already SPUN — one spin per issue ever |
| `~/.autospin-dryrun` | phase B | issues already announced in dry-run |
| `~/.autospin-refused` | phase B | `<issue>\|<reason>` already posted, so a refusal does not repeat |
| `~/.autospin-hold` | phase B | the last announced hold, so holds are edge-triggered |
| `~/.autospin-mode` | **keeper** | contains `live` to arm; anything else is dry-run |
| `/tmp/keeper-quiet`, `~/.keeper-quiet` | **keeper** | stop everything |
