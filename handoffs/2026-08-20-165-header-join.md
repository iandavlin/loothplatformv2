## 2. ⚠️ THE FLIP IS TWO SWITCHES. One of them is not mine.

`/lgjoin/` decides its own audience. `membership-pages/web/router.php` lists it

```
'lgjoin' => ['lgjoin.php', 'testgroup', 'public'],
```

and the wp_option **`lgms_stripe_pages_live`** picks which column applies. While
that option is off, the **pre-launch** column (`testgroup`) applies, and an
anonymous visitor — not an admin, not on the test-group list, holding no invite
— is handed `lg_membership_admin_gate_or_exit()`'s stub.

**Measured on dev2 2026-08-20, anon and cookieless:** `GET /lgjoin/` → HTTP 200,
33,221 bytes, `<title>Not available</title>`, `<h1>This page isn't available
yet</h1>`.

So **turning this flag on alone hands Ian a Join button that is wired perfectly
and lands nowhere.** Gate 79 §E holds it shut: while the header flag is OFF that
leg reports; the moment it is ON it becomes a hard assertion that anon
`/lgjoin/` is not the stub.

### The order to do it in

```bash
# 1. merge the branch (origin/main is already an ancestor of HEAD)
git -C ~/keeper-repo merge --no-ff 165-header-join

# 2. deploy — one pull
git -C ~/loothplatformv2-clean pull --ff-only origin main
#    NOTE: no new mu-plugin and no new webroot FILE, so neither of the two
#    deploy couplings applies here. bottom-nav.js already has its symlink.

# 3. the box-local flag — NOT an FPM env[]: dev2's pool files are symlinks into
#    the serving checkout, and an env flip dirties a tracked file in the one
#    checkout that must only ever pull.
cat > ~/loothplatformv2-clean/platform/config/header-join-stripe.local.php <<'EOF'
<?php
return array('enabled' => true);
EOF

# 3a. ⚠️ ALWAYS. `@` suppresses warnings, NOT parse errors, and this partial
#     renders on EVERY page — a typo here is a site-wide 500, not one quiet
#     feature. Every other malformation (empty / non-array / missing key /
#     unreadable) is handled and gated; this one cannot be.
php -l ~/loothplatformv2-clean/platform/config/header-join-stripe.local.php

# 4. THE SECOND SWITCH — WP admin, Settings → LG Member Sync, or:
#    wp option update lgms_stripe_pages_live 1
#    Without this, step 3 sends anon to "This page isn't available yet".
```

### Then prove it, don't assume it

```bash
cd ~/worktrees/165-header-join   # or wherever the gate lives post-merge
python3 tools/gates/header-join-gate.py
```

With both switches on, §D must report *"the ORIGIN is serving the ON state"* and
§E must **PASS** *"anon `/lgjoin/` is a real join page, not a refusal"*. If §E
